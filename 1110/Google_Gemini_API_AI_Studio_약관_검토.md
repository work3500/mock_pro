# Google Gemini API (Google AI Studio 경로) 약관 검토

| 항목 | 내용 |
| --- | --- |
| 검토일 | 2026-11-11 |
| 검토 대상 | Google AI Studio에서 발급한 API 키로 호출하는 Gemini API (`generativelanguage.googleapis.com`) |
| 검토 기준 | Google APIs 약관 + Gemini API 추가 약관, 그리고 추가 약관이 편입하는 데이터 처리 부속서 |
| 대조 조문 | 개인정보 보호법 제26조① · 제28조의8② / 시행령 제28조① · 제29조의10 / 「AI 도구 활용 정책」 v2.6 §2.1 · §4.2 · §4.4 |
| 상태 | 잠정 검토. 이용 조건 확인을 반영함(2026-11-11). 승인 목록과 의결 안건에는 반영하지 않음 |

검토의 한계는 두 가지다.

- 「[별첨] AI도구 위탁계약 조건 검토_r7」의 16개 항 틀은 저장소에 없다. 관리대장 02·05 시트에 드러난 조문과 정책 v2.6의 평가 항목을 기준으로 삼았다.
- 약관 원문을 조문에 대조한 결과이며 법률 판단은 아니다. 판정은 법무 확인이 필요하다.

## 확인된 이용 조건

요청자가 2026-11-11에 확인한 내용이다. 6절의 반영안은 이 조건을 전제로 한다.

| 항목 | 확인 내용 | 검토에 주는 영향 |
| --- | --- | --- |
| 이용 형태 | 애플리케이션이 API를 호출 | 13번 Upstage와 같은 자동 호출 경로. 임직원이 직접 입력하지 않음 |
| 키 발급 프로젝트 | 회사 명의로 결제되는 프로젝트 | 유료 구간 조건 적용. 학습에 쓰이지 않고 데이터 처리 부속서가 적용됨 |
| 사용 기능 | 그라운딩, File API, 캐싱, Interactions API, Live API 모두 사용하지 않음 | 프롬프트·응답의 보관은 오남용 탐지 로그(안내 문서상 55일)에 한정 |
| 호출 데이터 | 애플리케이션이 보내는 데이터에 개인정보가 없다고 봄 | 「제한」의 전제가 성립. 기술적으로 막아 둔 것은 아니므로 C7로 뒷받침 |
| 계약 당사자 | 구글 코리아 | Google 안내의 한국 청구지 당사자(Google Cloud Korea LLC)와 맞음. 정식 법인명은 청구서로 확인 |

## 1. 결론

1. **12번(Vertex AI)의 판정은 이 경로에 쓸 수 없다.** 계약 문서, 계약 당사자 결정 방식, 처리 위치 통제가 모두 다르다.
2. **무료 구간은 개인 등급에 해당한다.** 입력과 응답이 제품 개선에 쓰이고 사람이 검토할 수 있으며, 약관이 민감·기밀·개인정보 제출을 금지한다. 현재 이용은 유료 구간이라 해당하지 않는다.
3. **유료 구간은 위탁 계약의 형식은 갖췄다.** 학습에 쓰지 않고, 데이터 처리 부속서가 약관에 편입되어 있다.
4. **유료 구간에서도 처리 국가를 고정할 수 없다.** 리전 선택 기능이 없어, 다른 도구의 C2처럼 설정으로 해소되지 않는다. 이 검토에서 가장 큰 쟁점이다.
5. **회사 등급(등급 2) 요건을 채우는지 불확실하다.** SLA가 없고, 정책 §4.2의 8개 항목 중 충족으로 볼 수 있는 것이 3개다.
6. **권고**: 확인된 이용 조건이라면 유료 구간을 별도 행으로 상정하고 개인정보 입력은 「제한」으로 둔다. 앞으로 개인정보를 보내는 용도가 생기면 그 용도는 Vertex AI(12번)로 옮긴다.

## 3. 무료 구간과 유료 구간

같은 API라도 호출에 쓰는 Cloud 프로젝트에 따라 조건이 갈린다.

| 구분 | 무료 구간 (Unpaid Services) | 유료 구간 (Paid Services) |
| --- | --- | --- |
| 해당 조건 | 결제 계정이 없는 프로젝트의 API 키, 무료 할당량 | 활성 결제 계정이 연결된 Cloud 프로젝트의 API 키 |
| 제품 개선·학습 이용 | 이용함 | 이용하지 않음 |
| 사람 검토 | 검토자가 입력·출력을 읽고 주석을 달 수 있음 | 오남용 탐지에 걸린 건만 권한 있는 직원이 검토 |
| 개인정보 | "민감·기밀·개인정보를 제출하지 말 것" | 데이터 처리 부속서에 따라 처리 |
| 계약상 Google | Google LLC | 청구지 주소에 따라 결정 (4절 참조) |

AI Studio 웹 화면은 계정이 결제 프로젝트에 접근할 수 있거나 Workspace 기업 계정이면 유료 구간으로 취급된다.

같은 종류의 키가 프로젝트 설정 하나로 무료 구간이 되므로, 유료 구간으로 승인하더라도 키가 결제 프로젝트에서 발급됐는지 관리자가 확인해야 한다.

### 4.4 정책 v2.6 등급 요건 — §2.1, §4.2

§2.1은 등급 2의 계약 요건으로 ToS · DPA · SLA · 학습 OFF를 든다.

| 요건 | 판정 | 근거 |
| --- | --- | --- |
| ToS | 충족 | 사업자용 약관 |
| DPA | 충족 | 데이터 처리 부속서 편입 |
| SLA | 미충족 | Google 비교표: "기업 수준 지원·SLA 없음". 기본 약관 9a: 가용성 약정 없음, 8a: 사유·책임 없이 언제든 중단 가능 |
| 학습 OFF | 충족 | 유료 구간에 한함 |

§4.2의 8개 항목은 다음과 같다.

| 항목 | 판정 | 근거 |
| --- | --- | --- |
| ① 목적 외 처리 금지 | 충족 | 부속서 5.2·5.3 |
| ② 암호화 | 충족 | 부속서 부록 2 |
| ③ 접근권한 관리 | 일부 | 인증 수단이 API 키뿐임(Google 비교표). 사용자별 통제는 KTNET이 키 관리로 보완해야 함 |
| ④ 접속기록 2년 보관 | 미확인 | 약관에 규정 없음. KTNET 쪽 로그로 갖춰야 함 |
| ⑤ 데이터 저장 위치 | 미충족 | 위치 미특정 |
| ⑥ 사고 72시간 통지 | 미충족 | 부속서 7.2.1: "지체 없이". 시한 수치 없음 |
| ⑦ 재위탁 투명성 | 충족 | 목록 URL 공개, 30일 전 통지 |
| ⑧ 보안감사 공개 | 일부 | 부속서 7.4는 ISO 27001 유지를 약정하나, Google 비교표는 Gemini API에 "컴플라이언스 인증 없음"이라고 적음. 서로 맞지 않아 확인 필요 |

충족 3, 일부 2, 미충족·미확인 3이다. §4.2 기준으로는 "일부 항목 충족 → 등급 1"에 가깝다. 등급 확정은 AX추진실 1차 평가와 CISO·CPO 결재 사항이다.

§4.4 개인정보 위탁 적격 요건 가운데 무보관(ZDR), 감사권, 처리 위치 확인은 채우지 못한다. Google도 무보관 보장이나 기업용 데이터 처리 계약이 필요하면 Vertex AI를 쓰라고 안내한다.

## 6. 승인 목록 반영안

위원회 의결 사항이므로 관리대장과 의결 안건(24개 도구)은 고치지 않았다. 확인된 이용 조건을 전제로, 상정한다면 아래 값을 제안한다.

### 6.2 03 시트 원문 (안)

**조건·전제**

> 이용 형태상 임직원 개인정보 입력 업무가 없어 상시 제한 — 특약으로 해소되지 아니함 (애플리케이션 자동 호출 경로) / 회사 명의 결제 프로젝트에서 발급한 키만 사용(유료 구간) · 그라운딩·File API·캐싱·Interactions API·Live API 미사용 전제

**개별 선결과제**

> ① 이전 국가 미특정 — 글로벌 엔드포인트뿐이며 리전 선택 불가. 설정으로 해소되지 않아 국가 고정이 필요하면 Vertex AI로 전환 ② 계약 당사자는 한국 법인(Google Cloud Korea LLC)이나, 국외에서 이전받는 법인은 약관이 "Google Asia Pacific Pte. Ltd. 및/또는 그 계열사"로만 규정 ③ 보유기간 — 약관이 "a limited period of time"으로만 규정, 안내 문서상 55일 ④ 결제 프로젝트 키 강제 — 결제 계정이 없는 프로젝트의 키는 무료 구간 조건(학습 이용·사람 검토) 적용 ⑤ 자동 호출 경로의 PII 필터링·입력 스키마 통제 규정 별도 마련 ⑥ SLA 없음

### 6.3 값을 이렇게 정한 이유

- **「제한」**: 13번 Upstage와 같은 자동 호출 경로이고, 보내는 데이터에 개인정보가 없다고 확인됐다. 이 상태가 유지되도록 입력 스키마 통제와 PII 필터링을 규정으로 두는 C7이 함께 붙는다.
- **「조건부」가 아닌 이유**: 「조건부」는 KTNET 이행 3건이 끝나면 개인정보 입력이 열리는 값이다. 이 경로는 이전 국가(C2)가 벤더 쪽에서 해소되지 않아, 3건을 마쳐도 요건이 채워지지 않는다.
- **등급 「회사」**: 회사 명의 결제이고 데이터 처리 부속서가 적용되므로 회사로 제안한다. 다만 SLA가 없고 §4.2 충족이 3개여서 평가에서 개인 등급으로 정해질 수 있다. 그 경우 개인정보 입력은 「금지」가 된다.
- **무료 구간**: 행을 만들지 않는다. 등재되지 않은 플랜은 정책 §4에 따라 업무에 쓸 수 없다.
- **C2**: 다른 도구와 달리 해소 수단이 없으므로 05 시트에 그 사실을 적어 둔다.
- **C3**: 계약 당사자는 확인됐다. 남는 것은 정식 법인명 확인과, 국외에서 이전받는 법인을 고지에 어떻게 적을지다. 개인정보 입력이 「제한」인 동안은 국외 이전 고지가 필요하지 않아 급하지 않다.
